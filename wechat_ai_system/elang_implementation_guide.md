# 易语言WebSocket客户端实现指南

本文档提供了在易语言中实现WebSocket客户端连接Socket.IO服务器的详细步骤和代码示例。

## 准备工作

### 所需组件
1. 易语言WebSocket插件（如WebSocket.fne）
2. 易语言JSON解析组件
3. 易语言定时器组件（用于心跳机制）

## 实现步骤

### 1. 连接流程

```
// 连接WebSocket服务器
ws地址 = "ws://服务器IP:5000/socket.io/?EIO=4&transport=websocket"
连接成功 = 调用WebSocket.连接 (ws地址)

// 连接成功后发送认证消息
如果 (连接成功) 则
    认证消息 = "42[\"authenticate\",{\"user_id\":\"" + 用户ID + "\"}]"
    调用WebSocket.发送文本 (认证消息)
结束
```

### 2. 加入微信房间

```
// 认证成功后加入微信房间
加入房间消息 = "42[\"join_wechat_room\",{\"user_id\":\"" + 用户ID + "\",\"wechat_id\":\"" + 微信ID + "\"}]"
调用WebSocket.发送文本 (加入房间消息)
```

### 3. 消息处理

#### 接收消息
```
// 在WebSocket.收到文本消息事件中
收到的消息 = WebSocket.消息内容

// 解析消息类型（前两个字符）
消息类型 = 左边取 (收到的消息, 2)

// 处理不同类型的消息
如果 (消息类型 = "42") 则
    // 事件消息，提取JSON部分
    JSON部分 = 中间取 (收到的消息, 2, 取文本长度 (收到的消息) - 2)
    
    // 解析事件名和数据
    // 注意：这里需要使用JSON解析组件提取事件名和数据
    // 事件名在JSON数组的第一个元素，数据在第二个元素
    
    // 根据事件名处理不同事件
    如果 (事件名 = "auth_success") 则
        // 处理认证成功
        加入微信房间()
    否则如果 (事件名 = "new_message") 则
        // 处理新消息
        处理新消息(消息数据)
        
        // 如果消息需要确认
        如果 (消息数据.require_ack = 真) 则
            确认消息ID = 消息数据.id
            确认消息(确认消息ID)
        结束
    结束
否则如果 (消息类型 = "3") 则
    // 心跳响应，不需要特殊处理
结束
```

#### 发送消息
```
// 发送消息到服务器
发送消息函数 (联系人ID, 内容, 内容类型)
    消息数据 = "{\"user_id\":\"" + 用户ID + "\",\"wechat_id\":\"" + 微信ID + "\",\"contact_id\":\"" + 联系人ID + "\",\"content\":\"" + 内容 + "\",\"content_type\":\"" + 内容类型 + "\"}"
    完整消息 = "42[\"send_direct_message\"," + 消息数据 + "]"
    调用WebSocket.发送文本 (完整消息)
结束
```

#### 确认消息
```
// 确认收到消息
确认消息 (消息ID)
    确认数据 = "{\"user_id\":\"" + 用户ID + "\",\"message_id\":\"" + 消息ID + "\"}"
    完整消息 = "42[\"message_ack\"," + 确认数据 + "]"
    调用WebSocket.发送文本 (完整消息)
结束
```

### 4. 心跳机制

```
// 在定时器事件中（每15秒触发一次）
发送心跳 ()
    如果 (WebSocket.已连接) 则
        // 发送心跳包，必须是单个数字"2"
        调用WebSocket.发送文本 ("2")
    否则
        // 尝试重新连接
        重新连接()
    结束
结束
```

### 5. 断线重连

```
// 重新连接函数
重新连接 ()
    如果 (不是WebSocket.已连接) 则
        连接成功 = 调用WebSocket.连接 (ws地址)
        如果 (连接成功) 则
            // 重新认证
            认证消息 = "42[\"authenticate\",{\"user_id\":\"" + 用户ID + "\"}]"
            调用WebSocket.发送文本 (认证消息)
        结束
    结束
结束
```

## 注意事项

1. **消息格式非常重要**：
   - 事件消息必须以"42"开头，格式为`42["事件名",{数据}]`
   - 心跳包必须是单个数字"2"
   - 不遵循这些格式会导致服务器解析错误

2. **特殊字符处理**：
   - 在JSON中，引号(")需要转义为(\")
   - 中文和特殊字符需要正确编码

3. **心跳机制**：
   - 每15秒发送一次心跳包
   - 心跳包必须是单个数字"2"
   - 心跳响应通常是"3"开头的消息

4. **错误处理**：
   - 添加错误处理和日志记录
   - 实现断线重连机制

5. **消息确认**：
   - 收到require_ack=true的消息时，必须发送确认

2. 运行易语言客户端
3. 检查连接、认证和消息收发是否正常
4. 测试断线重连功能

## 常见问题

1. **连接失败**：
   - 检查服务器地址和端口是否正确
   - 确认服务器是否已启动

2. **认证失败**：
   - 检查用户ID是否正确
   - 确认消息格式是否符合要求

3. **消息发送失败**：
   - 检查是否已认证和加入房间
   - 确认消息格式是否正确

4. **心跳超时**：
   - 检查心跳定时器是否正常工作
   - 确认心跳包格式是否正确
